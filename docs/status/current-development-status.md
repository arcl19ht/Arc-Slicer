## 已实现

V2.4-A 已合入 `main`：对当前选中的完整片段使用源 `base.ogg` 手动试听，支持播放/暂停/恢复、循环、空格、有效倍速、播放头与切换片段停止旧播放。

V2.4-B 已实现：默认关闭且不持久化的自动试听开关；正式区间/有效倍速提交后的 200ms 防抖；连续提交最后一次生效；输入、拖动和手动播放期间取消 pending。自动试听不生成临时切片，不进入撤销历史，不标记导出 dirty。

V2.4-C 在 Windows EXE 验收中发现显式选择片段没有安排自动试听：卡片和时间线选择只刷新试听范围。修复后，开启自动试听时，显式选择会在刷新范围后安排 200ms 防抖；快速连续选择只保留最后一个片段。时间线已选中片段可单击定位并立即播放，拖动超过系统阈值则整体平移片段；首次点击未选中片段仅选择，端点 handle 优先。定位播放不修改边界、dirty 或历史；平移保持长度，级联组整体同步，并只提交一条历史。循环仍回到完整片段的原始起点。输入编辑、手动播放、删除、切歌和关闭窗口继续取消 pending。新增交互仍待 Windows EXE 人工复验。

## 当前开发：UI 清晰度与视觉层级

- 统一主题 token 和全局 QSS，避免裸 `QFrame` 选择器将卡片边框继承到 `QLabel`。
- 自动排序、循环和自动试听使用真实 switch；songlist、packlist、表单与导出选择使用方形勾选框。
- 主按钮启用态使用高饱和蓝色，禁用态保留灰色填充、深色文字和清晰边框；下拉框箭头、播放工具栏、片段卡片、导出与外部合并操作均有稳定静态层级。
- 自动排序关闭映射为手动顺序；旧 `sort_mode="manual"` 兼容映射为关闭自动排序，不改变片段顺序结果。
- 不改变切片/导出数据结构、播放/循环/自动试听语义，亦不改变 dirty 或撤销历史。
